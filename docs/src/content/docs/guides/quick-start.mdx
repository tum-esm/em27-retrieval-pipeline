## 1. Ensure system requirements

The pipeline was developed and is tested on Unix-based operating systems. You need to have the following dependencies installed on your system:

- [Python 3.11 or later](https://www.python.org/)
- [Git LFS](https://git-lfs.com/)
- unzip
- gfortran

You can check whether they are installed using:

```bash
python3.11 --version
git-lfs --version
unzip --version
gfortran --version
```

---

## 2. Clone or download the pipeline's code

Links: [repository](https://github.com/tum-esm/em27-retrieval-pipeline) | [all releases](https://github.com/tum-esm/em27-retrieval-pipeline/releases)

Using git clone (ssh):

```bash
git clone git@github.com:tum-esm/em27-retrieval-pipeline.git
cd em27-retrieval-pipeline
git switch --detach v1.11.1
```

... or git clone (https):

```bash
git clone https://github.com/tum-esm/em27-retrieval-pipeline.git
cd em27-retrieval-pipeline
git switch --detach v1.11.1
```

... or wget:

```bash
wget https://github.com/tum-esm/em27-retrieval-pipeline/archive/refs/tags/v1.11.1.tar.gz
tar -xzf em27-retrieval-pipeline-1.11.1.tar.gz && rm em27-retrieval-pipeline-1.11.1.tar.gz
cd em27-retrieval-pipeline-1.11.1
```

---

## 3. Create a virtual environment

```bash
python3.11 -m venv .venv
source .venv/bin/activate
```

You can of course use any other way to manage your Python environments.

---

## 4. Install the dependencies using

Using pip:

```bash
pip install ".[dev]"
```

... or [uv](https://docs.astral.sh/uv/):

```bash
uv sync --extra=dev
```

---

## 5. Explore and run the example

Contents:

- The `example/config` folder contains all configuration files required to run this example from raw interferograms to bundled retrieval outputs and GEOMS exports.
- The `example/data/inputs` directory contains some EM27/SUN interferograms, pressure observations recorded next the EM27/SUN and atmospheric profiles at the observation locations. When running your own retrievals, you only need to bring the interferograms and the pressure observations - the atmospheric profiles can be downloaded automatically using the pipelines GGG Profiles Downloader.
- The `example/data/outputs` directory will be empty after you clone the repository but will be filled with the different outputs after running the example.
- The `example/data/logs` directory will be empty after you clone the repository but will contain the log files of the pipeline produced during the example run.

Run it:

```bash
source .venv/bin/activate
cd example
bash run.sh
```

Have some patience on the retrieval process - the full example run should take around 2-5 minutes.
