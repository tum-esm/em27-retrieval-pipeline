The `config/config.toml` file configures all steps of the pipeline. You can use the `config/config.template.toml` file as a template to create your own configuration file. The only parts in this file that are required are the `version` number, the `metadata` and `data` sections. The `ggg_profiles_downloader`, `retrieval`, `bundle_exports` and `geoms_exports` sections can be omitted if you don't use these parts of the pipeline.

The next sections will describe how to define the [**EM27 metadata**](/em27-retrieval-pipeline/guides/em27-metadata), the **data** (input and output file paths), and how to use the **ggg_profiles_downloader**, **retrieval**, **bundle_exports** and **geoms_exports** features.

<Aside type="note">

The full schema specification and description of each parameter can be found [in the API Reference section](/em27-retrieval-pipeline/reference/config).

</Aside>

<Aside type="note">

If you upgrading from a pipeline version \<1.11.0 to a version \>=1.11.0, you will notice that we changed all configuration files from a JSON format to a TOML format with the release 1.11.0.

A full explanation on this change can be found in the the [Config Migration Guide](/em27-retrieval-pipeline/guides/config-migration).

</Aside>
