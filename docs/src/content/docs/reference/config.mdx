The `config.toml` file contains all information on how the EM27 Retrieval Pipeline should run. The key `version` specifies the version of the EM27 Retrieval Pipeline that this config file is compatible with. This is an example config. Below it you can find all possible configuration options supported by RETRO's latest version.
